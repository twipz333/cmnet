# MacroAction v0.1

Factorized macro-team intent: Kind + Target.

Disputed semantics (high-level):
- HOLD vs RESET: HOLD keeps current posture; RESET actively stops/reorganizes.
- RESET vs RETREAT: RESET is controlled re-organization; RETREAT is urgent distance-from-threat.
- PUSH vs SIEGE: PUSH is lane pressure; SIEGE is coordinated highground on ENEMY_BASE.
- CONTROL_OBJECTIVE vs TAKE_OBJECTIVE: CONTROL holds space around objective; TAKE directly starts/finishes killing it.
- FARM enemy side vs INVADE enemy side: FARM converts occupied space into resources; INVADE actively enters/contests.
- GROUP vs CONTROL_OBJECTIVE: GROUP tightens the main group without a concrete objective.

ActionKinds (14) and allowed targets are documented in code via the schema-valid validity table.
